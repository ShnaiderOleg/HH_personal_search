# HHSearch

Мониторинг вакансий hh.ru: парсинг веб-выдачи + дашборд + уведомления в Telegram/email.

> Официальный API `GET /vacancies` с апреля 2026 закрыт для соискателей (403), поэтому проект
> работает через парсинг веб-интерфейса `hh.ru/search/vacancy`. Это личный некоммерческий
> инструмент — использование противоречит ToS hh.ru и несёт риск блокировки. Пользуйтесь
> аккуратно и в разумных объёмах.

## Возможности

- Несколько поисковых запросов (позиция + регион), каждый со своим интервалом поллинга.
- Поллинг по расписанию (по умолчанию раз в 120 минут), дедупликация по id вакансии.
- Уведомления о новых вакансиях в Telegram (карточка: название, зарплата, компания, регион, ссылка).
- Email-дайджест (опционально).
- Веб-дашборд: статистика, график новых вакансий за 30 дней, фильтры, избранное.
- Опция парсинга под своим аккаунтом через cookies (риск бана аккаунта).

## Установка

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

## Настройка `.env`

1. **Telegram** (обязательно для уведомлений):
   - Создайте бота через [@BotFather](https://t.me/BotFather) → токен в `TG_BOT_TOKEN`.
   - Узнайте свой `chat_id` (например, через `@userinfobot`) → в `TG_CHAT_IDS` (несколько — через запятую).
2. **Email** (опционально): заполните `SMTP_HOST/PORT/USER/PASSWORD/FROM/TO`.
3. `HH_SESSION_COOKIES` — пусто для анонимного парсинга; для входа под аккаунтом вставьте
   cookies форматом `name=value; name2=value2`.

## Запуск

```powershell
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Если порт 8000 занят — укажите другой: `--port 8010`. Откройте http://127.0.0.1:8000 → добавьте
поиски → дождитесь первого поллинга (или нажмите `POST /api/poll/run`). Тест Telegram:
`POST /api/notify/test`.

Проверьте парсер вручную, прежде чем оставлять поллер работать:

```powershell
.venv\Scripts\Activate.ps1; python -c "import asyncio; from app.hh_scraper import HHScraper; from app.config import get_settings; s=get_settings(); sc=HHScraper(s); import asyncio; async def t():\n h=await sc.fetch_serp('python developer','1'); print([c.hh_id for c in sc.parse_serp(h)[:3]]); await sc.aclose()\n asyncio.run(t())"
```

## Как это работает

1. `poller.py` по расписанию (APScheduler) для каждого активного поиска запрашивает
   `hh.ru/search/vacancy?text=…&area=…&order_by=publication_time`.
2. `hh_scraper.py` парсит карточки по `data-qa`-атрибутам (название, зп, работодатель, регион, опыт, активность).
3. `vacancy_service.ingest_vacancies` сохраняет новые вакансии (дедупликация по id) и связывает с поиском.
4. Новые вакансии уходят в Telegram/email.
5. Дашборд читает данные из SQLite через REST API.

## Синтаксис поиска hh.ru (важно!)

- По умолчанию `text` ищет в **названии + описании** вакансии → отсюда «лишние» результаты.
  Включите опцию **«Только в названии вакансии»** (параметр `search_field=name`) для поиска
  строго по заголовку.
- Пространство = логическое **И** (`python developer` = python И developer в тексте).
- Точная фраза — в двойных кавычках: `"ИТ директор"`.
- Логическое **ИЛИ** — оператор `OR`: `python OR java`. Многословные операнды ОБЯЗАТЕЛЬНО
  оборачивать в кавычки, иначе hh ломает выражение и возвращает случайные вакансии:
  `"ИТ директор" OR "директор ИТ" OR "директор по информационным технологиям" OR CIO`.
- **Исключение** слова — оператор `NOT` (работает по словам): `python NOT qa`.
  Знаки `-` и `!` hh игнорирует (трактует как обычное «И»). Несколько слов исключаются
  повторением `NOT` — **не** группой `NOT (x OR y)` (группа с кириллицей ломает поиск → 0 результатов):
  `("ИТ директор" OR "директор ИТ" OR CIO) NOT продаж NOT менеджер`. Без скобок вокруг цепочки OR
  `NOT` применяется только к последней ветке — оборачивайте OR-часть в круглые скобки.

Пример поиска «ИТ-директор» только по названию:
```
"ИТ директор" OR "директор ИТ" OR "директор по информационным технологиям" OR CIO
```

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/searches` | список поисков |
| POST | `/api/searches` | создать поиск (`title`, `query`, `area_id`, `area_name`, `title_only`) |
| PUT | `/api/searches/{id}` | изменить поиск |
| PATCH | `/api/searches/{id}` | вкл/выкл `active` |
| DELETE | `/api/searches/{id}` | удалить |
| GET | `/api/vacancies` | вакансии с фильтрами (`search_id`, `q`, `salary_min/max`, `favorite`) |
| POST | `/api/vacancies/{hh_id}/favorite` | в избранное/убрать |
| GET | `/api/areas?q=` | подсказки регионов |
| GET | `/api/stats?days=30` | статистика для графиков |
| POST | `/api/poll/run` | ручной запуск поллинга |
| POST | `/api/notify/test` | тестовое Telegram-сообщение |

## Ограничения и риски

- hh.ru может показывать капчу/блокировать при частых запросах → поллер ставит на паузу
  и фиксирует ошибку в поиске. Увеличьте `REQUEST_DELAY_SECONDS`/`POLL_INTERVAL_MINUTES` при блокировках.
- Разметка сайта меняется → селекторы могут устареть; правки в `hh_scraper.parse_serp`.
- `first_seen_at` — время, когда вакансия впервые обнаружена нами (SERP даёт относительные даты).
- Для деплоя на сервере/по расписанию можно запускать `uvicorn` как сервис или через Task Scheduler.
